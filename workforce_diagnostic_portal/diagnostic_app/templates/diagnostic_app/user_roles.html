User Roles & Responsibilities

Each role has specific responsibilities designed to ensure comprehensive and fair hiring decisions

Level 1: Strategic Leadership

Ownership and strategic direction

👑

Founder

Strategic
Key Responsibilities:
  • Create and define job roles
  • Set strategic hiring priorities
  • Approve final hiring decisions
  • Oversee entire recruitment process
  • Access system analytics and reports
🤝

Co-Founder

Strategic
Key Responsibilities:
  • Create and define job roles
  • Collaborate on strategic hiring
  • Approve final hiring decisions
  • Support founder in oversight
  • Access system analytics and reports

Level 2: Executive Leadership

Execution and delivery management

💼

CEO

Executive
Key Responsibilities:
  • Review and assess candidates
  • Provide executive perspective
  • Participate in final decisions
  • Ensure alignment with business goals
  • Access analytics and insights
💰

CFO

Executive
Key Responsibilities:
  • Evaluate budget and salary proposals
  • Assess financial impact of hiring
  • Review compensation packages
  • Ensure financial sustainability
  • Access financial analytics
🔧

CTO

Executive
Key Responsibilities:
  • Assess technical requirements
  • Evaluate technical candidates
  • Define technical skill standards
  • Ensure technical team fit
  • Access technical analytics
⚙️

COO

Executive
Key Responsibilities:
  • Evaluate operational impact
  • Assess workflow integration
  • Review process efficiency
  • Ensure operational readiness
  • Access operational analytics
🚀

Project Head

Executive
Key Responsibilities:
  • Evaluate project-specific needs
  • Assess candidate project fit
  • Review project impact
  • Ensure project team compatibility
  • Access project analytics

Level 3: HR & Operations Support

HR and operational support functions

👥

HR Manager

Support
Key Responsibilities:
  • Manage recruitment process
  • Coordinate candidate assessments
  • Facilitate communication
  • Ensure compliance with policies
  • Manage candidate relationships
🎯

Recruiter

Support
Key Responsibilities:
  • Source and screen candidates
  • Conduct initial interviews
  • Manage candidate pipeline
  • Coordinate assessment logistics
  • Provide recruitment insights
📋

HR Executive

Support
Key Responsibilities:
  • Support recruitment activities
  • Assist in candidate evaluation
  • Manage documentation
  • Coordinate interview schedules
  • Provide administrative support
